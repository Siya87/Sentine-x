## 🎥 PRODUCTION CHECKLIST

### Before Recording:

**1. Prepare Test Data:**
- [ ] Sample phishing email (copy from script above)
- [ ] Test email for OSINT: test@example.com
- [ ] Incident report details ready
- [ ] Chat questions prepared

**2. Browser Setup:**
- [ ] Clear browser cache and cookies
- [ ] Close unnecessary tabs
- [ ] Disable browser extensions that might interfere
- [ ] Set browser zoom to 100%
- [ ] Use incognito/private mode for clean recording

**3. Application Check:**
- [ ] Verify deployed app is working: https://sentine-x-e5tt.vercel.app/
- [ ] Test all features before recording
- [ ] Check if backend API is responding
- [ ] Ensure no error messages appear

**4. Recording Setup:**
- [ ] Use screen recording software (OBS Studio, Camtasia, or Loom)
- [ ] Set recording resolution: 1920x1080 (Full HD)
- [ ] Frame rate: 30 or 60 FPS
- [ ] Audio: Clear microphone, no background noise
- [ ] Test audio levels before full recording

**5. Environment:**
- [ ] Quiet recording space
- [ ] Good lighting (if showing face)
- [ ] Stable internet connection
- [ ] Close notification apps (Slack, email, etc.)

### During Recording:

**1. Pacing:**
- [ ] Speak clearly and at moderate pace
- [ ] Pause between sections (easier to edit)
- [ ] Allow UI animations to complete
- [ ] Don't rush through features

**2. Cursor Movement:**
- [ ] Smooth, deliberate movements
- [ ] Highlight important elements
- [ ] Avoid erratic movements
- [ ] Use cursor to guide viewer's attention

**3. Timing:**
- [ ] Keep total video under 5 minutes
- [ ] Each feature demo: 30-45 seconds
- [ ] Allow time for loading states
- [ ] Don't linger too long on any screen

**4. Backup Plan:**
- [ ] Record in segments (easier to fix mistakes)
- [ ] Have script visible on second monitor
- [ ] Take multiple takes if needed
- [ ] Record extra footage for B-roll

### After Recording:

**1. Editing:**
- [ ] Cut out mistakes and long pauses
- [ ] Add transitions between sections
- [ ] Include text overlays for key points
- [ ] Add background music (optional, keep subtle)
- [ ] Add zoom effects on important UI elements
- [ ] Include captions/subtitles (highly recommended)

**2. Graphics to Add:**
- [ ] Opening title card with project name
- [ ] Text overlays for statistics (95% faster, etc.)
- [ ] IBM technology logos
- [ ] URL display: https://sentine-x-e5tt.vercel.app/

**3. Quality Check:**
- [ ] Watch entire video for errors
- [ ] Check audio levels (consistent volume)
- [ ] Verify all features are shown clearly

## 💡 PRO TIPS

1. **Practice First:** Do a complete run-through before final recording
2. **Use Teleprompter:** Have script visible but don't read robotically
3. **Show Real Results:** Use actual API responses, not mocked data
4. **Be Enthusiastic:** Show genuine excitement about the technology
5. **Handle Errors Gracefully:** If something doesn't work, have a backup plan
6. **Keep It Professional:** Clean desktop, professional browser bookmarks
7. **Add Personality:** Make it engaging, not just a feature list
8. **Focus on Value:** Always tie features back to business benefits
