## 10. TROUBLESHOOTING

### If Phishing Detector Doesn't Work:
- Try shorter email content
- Use URL analysis instead
- Check if backend API is responding

### If OSINT Investigation Doesn't Work:
- Try different email: john.doe@example.com
- Use IP address instead: 8.8.8.8
- Check API rate limits

### If Report Generator Doesn't Work:
- Simplify description
- Try different incident type
- Check if all required fields are filled

### If Chat Assistant Doesn't Work:
- Try simpler question: "What is phishing?"
- Check if session is active
- Refresh page and try again
